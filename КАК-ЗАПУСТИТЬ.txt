ПВЗ КАБИНЕТ — ПУСТОЙ, ДЛЯ НАСТОЯЩЕЙ РАБОТЫ

localhost телеграмму не виден. Это только просмотр сайта на своём компьютере.
Главный администратор: iwannabenever

1. База: https://neon.tech — скопируйте строку postgresql://
2. Закрытый репозиторий: https://github.com — файлы архива без node_modules
3. Сайт: https://vercel.com — переменная DATABASE_URL = строка из Neon
4. Один раз на компьютере: npm install и npm run dev, вход iwannabenever,
   в сотрудниках вставьте адрес сайта и нажмите «Подключить бота»
5. Будильник: https://console.cron-job.org каждую минуту на https://ВАШ-САЙТ/api/cron
   заголовок x-cron-secret, значение секрета в кабинете у главного администратора
6. В Telegram: /start и кнопка «Кабинет»

Часы точки: раздел «Пункты».
